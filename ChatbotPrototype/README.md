# ChatbotPrototype

This directory contains media assets and prototypes for the FUAARK Shopping Assistant:

- **Website/**:
  - `index.html`: Video preview web player.
  - `fuaark-demo.mp4`: Screen recording demo of the web shopping assistant (stream-optimized MP4).
  - `fuaark-2026-10-11_13.59.53`: Original Matroska screen recording.
  - Screenshots: Captured high-resolution UI states.
- **Whastapp/**:
  - WhatsApp Business UI mockups of all conversational flows.
