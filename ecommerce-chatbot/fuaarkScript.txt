--------------------------------------------------------------------------------
11.2 Natural Language Intent Triggers (Regex Grounded)
--------------------------------------------------------------------------------
- "where is my order" / "track my package" / "order status"
  -> Routes to trackFlow()

- "my orders" / "order history" / "past purchases"
  -> Routes to showOrders()

- "I want to return an item" / "exchange size" / "refund"
  -> If logged in with orders: routes to returnFlow()
  -> If no orders / not logged in: routes to Return Policy info block

- "what are your delivery charges?" / "when will it be delivered?"
  -> Routes to Shipping Information info block

- "any discount coupon?" / "promo codes" / "sale"
  -> Routes to Current Offers info block

- "show me gym clothes" / "browse collections" / "buy trackpants"
  -> Routes to shopFlow()

- "tell me about polo t-shirt" / "product description"
  -> Routes to productDescriptionFlow()

- "view cart" / "checkout now" / "show my bag"
  -> Routes to cartFlow()

--------------------------------------------------------------------------------
